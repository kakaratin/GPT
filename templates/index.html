📖 How It Works

🔄 Round-Robin Distribution

Unlike spam tools, this app rotates through all your targets. Each question goes to a different user, cycling through your list evenly. This makes it natural and fair.


Example:

  • Question 1 → User A
  • Question 2 → User B
  • Question 3 → User C
  • Question 4 → User A (starts over)

⏱️ Smart Delays

The app waits a random time between each send (between min and max delay). This:

  • ✅ Avoids rate limits from NGL
  • ✅ Makes activity look natural (not bot-like)
  • ✅ Prevents IP bans

🎲 Random Elements

Every request uses:

  • 🔀 Random Android user agent (mimics real phone)
  • 🔀 Random device ID (unique per message)
  • 🔀 Random question selection
  • 🔀 Random delay timing

This makes detection nearly impossible!
