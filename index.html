KingDev Cloud Toolkit

Embedded access to cloud.kingdev.site/tool.php with built-in speech-to-text helpers powered by Buster.

Tool Portal

The tool is sandboxed below via an iframe so you can keep the solver tools handy in the same tab.

If the iframe shows a blank page or a browser warning, open the tool in a new tab above. Some hosts disallow embedding for security reasons.

Speech-to-Text Recognizer

This client reuses open-source components from the Buster project (GPL-3.0). Provide your own API credentials for the supported providers.

Download the CAPTCHA audio (or record your own) and drop it here. The helper will trim quiet edges and convert it to WAV before calling the API.
